## Version 1.0.0 - Initial Release

**Created by Sushant**

### Added
- ✨ **Dart-Optimized Region Folding**: Clean `//region` and `//endregion` syntax without # symbols
- 🎯 **Dart-First Design**: Built specifically for Dart and Flutter developers
- ⚡ **Zero Configuration**: Works immediately with Dart files out-of-the-box
- 🏗️ **Flutter Widget Organization**: Perfect for organizing lifecycle methods, build methods, and widget structure
- 📦 **Class Organization**: Ideal for grouping properties, constructors, public methods, and private methods

### Features
- **Region Folding Commands**:
  - Collapse all regions in Dart files
  - Wrap selected code with region markers
  - Select and manipulate regions easily
  - Delete region tags with or without content

- **Keyboard Shortcuts**:
  - `Ctrl+M Ctrl+R`: Wrap selection with region tag
  - `Ctrl+Shift+M Ctrl+Shift+R`: Collapse default regions

- **Developer Experience**:
  - Seamless integration with Dart and Flutter development workflow
  - Automatic detection and folding of region blocks
  - Improved code readability and navigation
  - Reduced visual clutter in complex files
  - Perfect for Clean Architecture implementations

### Technical Details
- Supports standard Dart comment syntax: `//region` and `//endregion`
- Lightweight with minimal performance impact
- Custom SVG icon designed for Dart developers
- Comprehensive documentation with best practices

### Best Practices Included
- Flutter widget lifecycle organization
- Class structure organization (properties, constructors, methods)
- Clean Architecture pattern support
- Code readability improvements
